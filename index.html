Rheology Processing SOP

PMFL hydrogel rheology data: reproducible extraction, unit conversion, Origin import and project delivery.

Data integrity first. Raw files are read-only. No deletion, interpolation, smoothing or fabricated points are permitted.

Delivery contract

01

Versioned output

Repeated processing never overwrites an earlier result: R01_, R02_, and so on.

02

Excel data file

One workbook with normalized plot data and traceable raw/converted values.

03

Origin project

One matching .opju project containing imported data, axes and plots.

04

No public raw data by default

This website documents the workflow only. Experimental raw data remain private unless separately approved.

Critical checks before delivery

SS time sweep

Use the true cumulative Time t, not Step time. Convert minutes to seconds only when no native seconds column exists. Keep switching gaps and all original points. Retain only rows where both G′ and G″ are numeric.

Units

G′ and G″ exported in MPa must be converted in new columns to Pa. Viscosity already exported as Pa·s must not be converted again.

Origin verification

After saving, reopen the project and confirm the X/Y column mapping, axis scale, data points and legend labels. Default A/B/C labels must be replaced by physical labels.
